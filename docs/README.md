# Documentation and test reports

- [HTML source-code API documentation](html/index.html): includes every Python module, module/function docstrings and line-numbered annotated source. Generate using `python scripts/generate_docs.py`.
- [Automated HTML test report](test_report.html): generated by pytest-html from actual pytest execution.
- [JUnit test results](test-results.xml): pytest machine-readable results.
- [Test functions](../tests/): grouped-engine splits, remaining-life labels, sensor selection, prediction clipping, input archives and official saved metrics.

Run locally:

```bash
python -m pip install -r requirements-dev.txt
python scripts/generate_docs.py
python -m pytest -q --junitxml=docs/test-results.xml --html=docs/test_report.html --self-contained-html
```

The GitHub Actions workflow repeats these steps on each push to main and commits updated documentation/results. NASA training/test source data is not redistributed here.
